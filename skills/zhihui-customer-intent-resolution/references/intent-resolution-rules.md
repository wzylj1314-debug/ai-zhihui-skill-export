# 客服意图判断规则

本文件给 `zhihui-customer-intent-resolution` 使用。任意 Agent 只需要按这里的规则处理客户实时问题。

## 一、核心目标

把客户原话转成安全、可执行的客服处理结果：

- 判断客户真实意图。
- 推荐合适功能或操作路径。
- 回答常见 FAQ。
- 给出排障步骤。
- 判断是否需要转人工。
- 避免价格、合同、版权、退款、API、隐私等敏感承诺。

## 二、意图类型

| 意图类型 | 适用情况 | 处理方式 |
|---|---|---|
| 功能推荐 | 客户描述目标但不知道用哪个功能 | 推荐一个主功能，必要时给备选功能 |
| 操作咨询 | 客户问怎么操作、在哪里点、素材怎么准备 | 给步骤和注意事项 |
| FAQ | 高频固定问题 | 给简洁标准回复 |
| 效果排障 | 生成失败、图片模糊、试衣不自然、效果跑偏 | 判断可能原因，给排障步骤 |
| 风险转人工 | 价格、合同、版权、退款、API、隐私、私有化等 | 不承诺，给安全回复并转人工 |
| 投诉升级 | 情绪强烈、反复失败、明确投诉 | 安抚并升级人工 |

## 三、风险转人工规则

必须转人工的内容：

- 价格、折扣、套餐、发票、付款、退款。
- 合同、法务、版权、商用授权、侵权责任。
- API、私有化部署、企业集成、数据安全承诺。
- 账号开通、权限、异常扣费。
- 客户投诉、反复失败、情绪强烈。
- Agent 低置信度，无法确认真实答案。

安全回复原则：

- 先承认问题或需求。
- 不擅自报价、不承诺合同或版权结论。
- 说明需要人工确认。
- 给出下一步会转给同事处理。

## 四、排障规则

| 问题 | 可能方向 |
|---|---|
| 图片模糊 | 检查原图清晰度、使用高清放大、降低复杂修改 |
| 试衣不自然 | 检查模特姿势、衣服图完整度、遮挡和角度 |
| prompt 不生效 | 明确保留项和修改项，减少互相冲突的要求 |
| 背景去除不干净 | 换更清晰图片，检查主体边缘和背景复杂度 |
| 矢量化失败 | 检查图案清晰度、颜色层次、边缘复杂度 |
| 反复失败 | 转人工复核 |

## 五、混合场景

| 输入 | 处理方式 |
|---|---|
| 客户问功能，同时问价格 | 先回答可回答的功能问题，价格部分转人工 |
| 客户反馈失败，同时情绪强烈 | 归为投诉升级或风险转人工 |
| 客户问能不能商用 | 不做版权/商用承诺，转人工 |
| 客户问哪个功能适合 | 推荐功能，补充素材准备建议 |
| 客户长篇沟通里有购买意向 | 当前 Skill 只处理即时客服问题，补充 `business_signal_hint` |
